# Manual de Usuario - App SendMessage

¡Bienvenido a **SendMessage**! Esta aplicación te permite enviar mensajes de texto de una pantalla a otra de forma sencilla y rápida.

---

## 📖 Cómo enviar un mensaje en 3 sencillos pasos

```
  ┌────────────────────────┐      ┌────────────────────────┐      ┌────────────────────────┐
  │  PASO 1: Escribir      │ ───► │  PASO 2: Enviar        │ ───► │  PASO 3: Ver resultado │
  │  Escribe tu mensaje    │      │  Toca el cuadro de     │      │  Tu mensaje aparece    │
  │  en el cuadro de texto │      │  texto y pulsa Enviar  │      │  en la nueva pantalla  │
  └────────────────────────┘      └────────────────────────┘      └────────────────────────┘
```

### Paso 1: Escribe tu mensaje
Abre la aplicación **SendMessage**. En la pantalla principal verás un cuadro de texto con el mensaje *"Escribe aquí tu mensaje..."*. Toca sobre él e ingresa el texto que quieras enviar.

### Paso 2: Toca el botón "Enviar"
Una vez redactado tu mensaje, presiona el botón morado con la etiqueta **"Enviar"** ubicado al final de la pantalla.

### Paso 3: Disfruta de tu mensaje enviado
La aplicación te llevará automáticamente a una segunda pantalla en la que podrás ver tu mensaje desplegado de forma clara.
